## [!UICONTROL General]

![Bulk API > Allgemein](./assets/bulk-api.png)<!-- zoom -->

| Feld | [Umfang](../../getting-started/websites-stores-views.md#scope-settings) | Beschreibung |
|--- |--- |--- |
| [!UICONTROL Maximum Entities Per Bulk Request] | Global | Zeigt die maximale Anzahl von Entitäten an, die in einer einzelnen Massenanfrage verarbeitet werden können. [Bulk-APIs](https://developer.adobe.com/commerce/webapi/rest/use-rest/bulk-endpoints/){target="_blank"} werden empfohlen, mehrere Aufrufe in einer einzigen Anfrage zu kombinieren, um die Anzahl der Anfragen zu reduzieren und die Leistung zu verbessern. Kunden können eine Erhöhung des [!UICONTROL Maximum Entities Per Bulk Request] anfordern, indem sie sich an den [Adobe Commerce-Support](https://experienceleague.adobe.com/de/support?support-tab=home#support) wenden. Adobe prüft Ihren Anwendungsfall und entscheidet, ob eine Erhöhung der Größe Ihrer Massenanfrage angemessen ist. |
